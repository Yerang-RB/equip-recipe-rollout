# 탐침(probe) 스크립트

리스크 원장의 **실서버 시나리오**를 실제로 밟아 본 스크립트들입니다. 판정에 쓰인 증거이지 제품 코드가 아닙니다
(테스트 스위트·게이트 어디에서도 실행되지 않습니다).

| 파일 | 무엇을 쟀나 |
|---|---|
| `probe.sh` | 레저 B7(ADMIN 자기 강등)·B12(로그인 스로틀 없음)의 나쁜 갈래가 **다른 사용자의 정당한 요청을 무효화하는지** |
| `_probe-smoke.sh` | 위 탐침이 `source`하는 `scripts/smoke.sh` 사본(호출·단언 헬퍼 재사용) |
| `run.py` | 씨앗(뮤테이션)을 하나씩 심고 지목 테스트를 돌린 뒤 복원하는 실행기 |
| `gates.py` | 게이트 씨앗(G 행)을 같은 방식으로 돌린 실행기 |

결과는 `docs/review/findings-handled.md`의 「레저」 행과 `PROGRESS.md` 「리스크 원장」·「씨앗 표」에 있습니다.
